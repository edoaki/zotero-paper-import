# 詳しい使い方

インストールの手順は [トップページの日本語ガイド](../README.md) をご覧ください。

## 論文を取り込む

⌘Pでコマンドパレットを開き、「Zotero Paper Import: Zoteroから論文を取り込む」を選びます。左リボンのダウンロードアイコンでも開けます。

タイトル・著者・年で検索し、論文を選ぶと次の形式で保存されます。

```text
設定した保存先/
└─ smith2025/
   ├─ smith2025.md
   └─ 本文.pdf
```

PDF添付が複数ある場合は、本文と一緒に保存する補足資料を選びます。補足資料は別名で同じフォルダに保存します。PDFのダウンロードを確認できない場合は理由を表示し、「ノートだけ保存」を選べます。後からZoteroでPDFを取得し、ノートを更新できます。

同じ論文をもう一度選ぶと既存のノートを開きます。ファイル名を比較するだけでなく、取り込み元のZoteroデータベース・ライブラリ・アイテムキーで照合します。同じデータベースからの取り込みは、保存先の設定変更や保管庫内の移動後も既存ノートを再利用します。

## 名前の設定

- **著者名＋年**：標準設定。AI不要です。Zoteroに記録された第一著者の姓と出版年を使います。年不明なら `nd`、著者不明ならアイテムキーを使います。
- **手法名**：AIが論文の提案手法・モデルの名前を確認します。比較対象や既存モデルを誤って採用しないよう指示し、判断根拠をノートに残します。
- **カスタムルール**：自分の言葉で命名ルールを書き、名前を付けて保存できます。複製・JSON形式での書き出し・読み込みに対応します。

AIが判断できない、または接続できない場合は、必ず著者名＋年で保存し、代替した理由を表示・記録します。手入力を求めることはありません。設定変更だけで既存フォルダは改名されません。既存ノートを開いて「現在の命名設定で改名」コマンドを明示的に実行した場合に適用します。

Zoteroに記録された書誌情報が誤っていれば、AI不要の命名もその情報に従います。必要なら先にZotero側を修正してください。保管庫側の名前はZoteroの引用キーへ書き戻しません。

## AI CLIを使う場合

AI命名を選ぶと、CLI設定が表示されます。Codex、Claude Code、OpenCode、Google Gemini CLIを選択できます。OpenCodeとGemini CLIは実験的対応です。

1. 選んだCLIをインストールし、ターミナルでログイン・モデル設定を済ませます。
2. プラグインで「検出」を押します。見つからない場合は実行ファイルの場所を指定します。
3. モデルを一覧から選び、「AI接続テスト」で動作を確認します。モデル名を入力する必要はありません。迷ったら「自動」を選んでください。

接続テストもモデルの利用枠を消費する場合があります。論文取り込み時は、書誌情報・抽出したPDF本文・命名ルールを選択したCLIへ渡します。送信先・料金・利用上限はそのCLIで設定したサービスに従います。プラグイン自体はAPIキーを保存しません。

Codexは認証を再利用し、個人の設定・フック・MCPを読み込まないモードで動かします。モデルはCLIから取得した一覧で選べます。`--ignore-user-config` に対応した最近のCLIが必要です。Claude Codeではツール・MCP・フックを無効にした呼び出しを使います。OpenCodeではツールを許可しない専用エージェントを使います。Gemini CLIでは読み取り専用モードとツールを拒否するポリシーを使い、一時フォルダの設定でフック・拡張機能を抑制します。

Claude CodeはSonnet・Opus・Haiku、Gemini CLIはAuto・Pro・Flash・Flash-Liteを選べます。これらはCLIが対応モデルに読み替える種類名です。実際に使えるモデルはログイン先と契約によります。OpenCodeはCLIのモデルカタログを取得して表示します。

本文抽出はプラグインに同梱しています。OCRは行いません。最大200ページ、約18万文字をページごとの抜粋として渡すため、スキャンや複雑な表では名前を確認できない場合があります。AIが誤る可能性は残るので、ノート内の根拠を確認できます。

## ノートとPDFを更新する

文献ノートを開いて「この論文の情報・PDFを更新」を実行します。以前選んだPDFと書誌情報を取得し直します。

自分のメモは `<!-- zpi:generated:start -->` と `<!-- zpi:generated:end -->` の**外側**に書いてください。マーカー内はテンプレートから再生成する範囲です。プロパティの `zpi` は取り込み対応とPDFの検証情報なので編集しないでください。

更新前のノートとPDFは、保管庫の設定フォルダ内 `plugins/zotero-paper-import/backups/` にバックアップします。自動削除しないため、不要になったものは利用者が整理してください。

保管庫側のPDFをiPadなどで編集した場合は上書きせず停止します。元のPDFがZoteroから削除された場合も、保管庫のコピーを勝手に削除しません。PDFの注釈を書き戻したり、両方の注釈を統合したりする機能はありません。

## iPadで読む

Macで作成したノートとPDFをiCloudなどで同期し、iPadにダウンロードしてから開きます。iPadでこのプラグインやAI CLIを動かす必要はありません。オフラインにした状態で、文献ノートのPDFリンクから開けるか確認してください。

プラグイン自体はクラウド同期を行わず、iPad側のダウンロード状態も制御しません。

## ベータ版の範囲

1回につき1論文、1PDFにつき128 MiBまでです。検索結果は最新100件まで表示するので、必要に応じて検索語を絞ってください。既にPDFを取り込んだ論文へ、新しく増えた補足資料を追加選択する画面は未実装です。

Mac以外の実機動作や、複数のデスクトップで異なるZoteroデータベースから同じ保管庫を更新する運用は未検証です。別データベースの同じキーは自動統合せず停止します。自動分類・AI要約・Zoteroへの書き込み・Zotero注釈の抽出は行いません。
