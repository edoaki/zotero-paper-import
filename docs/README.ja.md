# 詳しい使い方

初めて使う場合は [トップページの入れ方・最初の設定](../README.md) から進めてください。

## 論文の名前を変える

設定の「命名方式」で選びます。

| 方式 | フォルダ名 |
| --- | --- |
| 著者名＋年 | 例：smith2025。AI不要 |
| 手法名 | AIが論文中の手法名を確認して付ける |
| 自分のルール | 登録した文章の指示に沿ってAIが付ける |

AIが命名できなかった場合は、著者名＋年で保存します。設定を変えても、既存の論文名は変わりません。既存の名前を変更したい場合は、そのノートを開いて「この論文を現在の命名設定で改名」を実行します。

## AIを使う

設定の「使用するAI」で、Codex・Claude Code・OpenCode・Antigravity CLIから選びます。見つからない場合は、同じ画面にインストール・ログインの手順が表示されます。

導入後に「再検出」→「AI接続テスト」を押してください。検出済みなら、接続テストだけで構いません。モデルは一覧から選び、迷ったら「自動」にします。

AI利用時は、論文ノート・PDFから抽出した本文・分類先の説明などを選択したAIサービスに送信します。料金や利用枠は、そのサービスの契約に従います。[動作確認の範囲](TESTING.md)

## 論文を整理する

「整理」タブで、未整理フォルダ内の論文を押します。AIが分類先を選び、ノートとPDFをフォルダごと移動します。

分類フォルダに `分類.md` があれば、その説明を判断に使います。適切な分類がなければ、新しい分類フォルダと説明を作ります。判断できなければ未整理に残し、理由を表示します。

リンクを保つため、Obsidianの **設定 → ファイルとリンク → 内部リンクを常に更新** をオンにしてください。

分類先が違った場合は、「整理結果」から「分類先を変更」を押して選び直します。追記したメモやPDFの編集を保持し、手動で選んだ分類先に固定します。

## 既存ノートのZoteroキーを補完する

設定の「キーを補完」を開き、Zoteroライブラリを選んで、対象ノートの「照合して補完」を押します。

ノートのDOI・arXiv IDと一致する論文が1件だけ見つかった場合に、Zoteroキーとリンクなどを追加します。本文は変えません。識別子がない場合や候補が複数ある場合は、理由を表示して止まります。

## 論文の情報やPDFを更新する

文献ノートを開き、「この論文の情報・PDFを更新」を実行します。このプラグインで取り込んだノートが対象です。

自分のメモは「自分のメモ」欄へ書いてください。更新時も保持します。保管庫側でPDFを編集している場合は、そのPDFを上書きせず停止します。

## 処理が進まない・論文が出てこない

| 状態 | 対処 |
| --- | --- |
| 取り込みたい論文が出てこない | 「取り込み済みで非表示の論文と理由」を開き、既存ノートを確認します。 |
| 整理したい論文が出てこない | 「整理できない項目と理由」を開きます。ノートが複数ある場合などは、対処方法を表示します。 |
| PDFを取得できない | ZoteroでPDFを開いてダウンロードしてから再試行します。 |
| 「確認待ち」になっている | 「処理状況を見る」からPDFを選択するか、ノートだけ保存するかを選びます。 |
| AIが動かない | 設定の導入・ログイン案内と「AI接続テスト」を確認します。 |
| 再起動後に処理が止まっている | 処理状況から「再試行」を押します。 |

## iPadで読む

Macで取り込んだノートとPDFをiCloudなどで同期し、iPadへダウンロードしてから開きます。iPad側でこのプラグインを動かす必要はありません。

外出前に通信を切り、ノート内のPDFリンクから開けるか確認してください。iPadのオフライン実機検証は未実施です。
